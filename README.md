# MargoTools - Data Scrapper

Narzędzie ułatwiające zbieranie danych z gry Margonem (mapy, przejścia, NPC, dialogi, battleNPC) za pomocą skryptu Tampermonkey.

---

#### Instrukcja
Odpalamy skrypt. Następnie chodzimy po wybranych mapach i klikamy we wszystkie npc by zgarnąć dialogi. Bijemy mobki by wyciągnąć dane o battle_npc. Wszystko na bieżąco się zapisuje do bazy. Podgląd jest pod fioletowym widgetem. Dodatek do margonem stworzony pod NI.


---

## Wymagania
* Konto Margonem (najlepiej multi by bana nie dostać).
* Przeglądarka internetowa z zainstalowanym rozszerzeniem **Tampermonkey**.
